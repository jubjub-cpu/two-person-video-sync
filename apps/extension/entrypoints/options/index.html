Playback defaults

Site permissions

Control where the extension can detect and synchronize video.

The extension normally asks only for the site you enable. You can optionally grant all website access for a more seamless experience.

Privacy-safe diagnostics

Export troubleshooting details without exposing private viewing data.

Diagnostics contain recent state transitions, latency, drift, adapter choice, and errors. Room codes, secrets, full URLs, titles, page contents, and account data are removed.

What this extension shares

A narrow set of playback details—and nothing from the video itself.

Only video identity, timing, play/pause, rate, and buffering state are sent to the synchronization service. It never captures or sends audio, video, cookies, passwords, or viewing-account details.

Both viewers need their own legitimate access to the same video. Volume, captions, language, quality, and fullscreen remain personal.
